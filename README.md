# Projects
---

### Finance Mate
A microservice-based application designed for personal finance management, extended with a recommendation module based on user data analysis. The business logic was developed using Spring Boot, while asynchronous communication between services is handled by RabbitMQ. The recommendation module uses machine learning implemented in Python. The user interface was developed using React.
🔗 [Finance Mate](https://github.com/CountToFour/finance-mate)

### Healthy
A distributed IoT system for real-time monitoring of patients’ vital signs. The system processes streaming data and applies machine learning models for anomaly detection and health analysis. It uses InfluxDB for time-series data storage and was developed as a multi-service architecture project.
🔗 [Healthy](https://github.com/247659/Healthy)

### Plantify
A mobile application designed to help users care for their houseplants without requiring specialized knowledge. The application features plant identification based on photos and an AI-powered chatbot for interactive assistance. The backend was developed using Spring Boot, while the mobile application was built with Flutter. User data and plant information are stored using Supabase.
🔗 [Plantify](https://github.com/247659/Plantify)

### Cloud App
A serverless application built on AWS, using AWS Lambda to handle file uploads and downloads with Amazon S3.
🔗 [Cloud App](https://github.com/CountToFour/portfolio/tree/main/clouds-app)

### Video-Sent
A Django-based application that retrieves smartphone reviews from YouTube and generates concise summaries of key aspects, such as the display, camera, and other specifications. The results are presented to users through a frontend built with React.
🔗 [Video-Sent](https://github.com/CountToFour/Video-Sent)

### E-Commerce

### Humanitarian Aid Cordination System
A Spring Boot-based system designed to support the coordination of aid efforts during crisis situations, such as natural disasters and ecological catastrophes. Developed as part of a 16-person team.
🔗 [SKPH](https://github.com/WiktorGlaner/System-koordynacji-pomocy-humanitarnej-SKPH-)

### Rently
